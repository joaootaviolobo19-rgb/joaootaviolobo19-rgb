## Projetos selecionados

### Sistema de Gestão de Patrimônio e Operações de TI

Aplicação web para gestão de bens patrimoniais e acompanhamento de movimentações, colaboradores, férias, ramais e reuniões. Utiliza Flask, SQLAlchemy e PostgreSQL, com suporte a persistência em arquivos CSV/JSON. O repositório é privado.

### Painel de Jornalismo

Painel que reúne dados meteorológicos de diferentes fontes e módulos para notícias, economia e tendências. Inclui cálculo de indicadores de consenso e atualização periódica dos dados. Desenvolvido em Python e Flask. O repositório é privado.

### Painel de Clima

Aplicação independente para consulta e visualização de dados meteorológicos, previsões, alertas e indicadores configuráveis. Utiliza coletores de múltiplas fontes e uma interface web. O repositório é privado.

### Synapse — Base de Conhecimento de TI

Aplicação para registrar soluções técnicas e recuperá-las por busca semântica, com possibilidade de síntese de respostas usando modelos locais. Desenvolvida com Flask, ChromaDB, Sentence Transformers e Ollama. O repositório é privado.

### Fiscare Growth Hub

Landing page institucional para a Fiscare Assessoria Empresarial, com conteúdos informativos e fluxo de diagnóstico em múltiplas etapas. Desenvolvida com React, TypeScript e TanStack Start. O formulário está em modo de demonstração e ainda não envia dados a um serviço externo.
